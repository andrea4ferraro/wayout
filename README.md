# Token Vesting Calculator

A Go command-line application for simulating token vesting schedules.

The application calculates unlocked tokens, remaining supply, and generates a future vesting calendar.

## Features

- Cliff support
- Monthly vesting
- Progress calculation
- JSON export
- Vesting calendar

## Run

```bash
go run ./cmd
```

## Example

```
Unlocked: 325000

Locked: 675000

Progress: 32.5%
```
